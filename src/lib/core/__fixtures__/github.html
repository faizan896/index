quill

A tiny, fast Markdown parser written in Rust. Quill turns CommonMark into HTML in a single pass, without allocating a syntax tree, and it is small enough to read in an afternoon.

Why another Markdown parser?

Most Markdown libraries are built for flexibility. They parse the whole document into a tree, let plugins rewrite it, and render the result at the end. That design is right for static site generators, but it is wasteful when all you need is to turn a comment or a chat message into safe HTML as quickly as possible. Quill is built for that case. It reads the input once, writes HTML as it goes, and never holds more than one block in memory.

The result is a parser that handles typical documents several times faster than tree-based alternatives and uses a constant amount of memory regardless of input size. It passes the full CommonMark specification test suite, and every release is fuzzed for at least a day before it is published.

Installation

Add the crate to your project with Cargo:

cargo add quill-md

Quill has no required dependencies. The optional simd feature enables faster scanning of long lines on x86-64 and ARM processors.

Usage

let html = quill::to_html("Hello, *world*!");
assert_eq!(html, "<p>Hello, <em>world</em>!</p>\n");

For streaming input, wrap any reader in a quill::Stream and pull rendered HTML from it in chunks. This is useful when rendering large documents straight into an HTTP response, because the first bytes reach the client before the whole document has been parsed.

Safety

By default Quill escapes raw HTML in the input and drops links with dangerous schemes such as javascript:. You can opt into raw HTML for trusted input, but the default is meant to be safe for user-generated content without further sanitising.

Contributing

Bug reports and pull requests are welcome. Please run the test suite and the fuzzer for a few minutes before opening a pull request that touches the block parser, and include a failing test for any bug you fix. Discussion of larger changes is best started in an issue first.
